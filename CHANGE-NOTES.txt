VIDEO TRIM STUDIO — media bin, multi-track B-roll and audio lanes
=================================================================

HOW TO INSTALL
--------------
Unzip this file over your existing project folder and let it overwrite the
files inside. Then DELETE these three files from your copy (they are obsolete
and no longer used by the app):

    BROLL-AND-FONTS.md
    static/broll.js
    vts/broll.py

Nothing else has to be removed. No Python packages were added. Restart the
server (run.bat) and hard-reload the page (Ctrl+F5) so the browser picks up
the new JavaScript.

Read MEDIA-BIN-AND-MULTITRACK.md for the feature guide.

THE THREE BUGS
--------------
1. "The multi video cannot overlapping (so, user just can see only 1 video)"
   FIXED. Tracks now composite. Dropping a clip on V2 lays it over V1 instead
   of pushing it aside, and the program monitor shows one <video> layer per
   visible track, scaled and positioned the way the export will be.

2. "The lane of audio in timeline is missing"
   FIXED. There are now audio lanes A1..An under the picture tracks. A clip's
   sound starts linked to its picture (V1 -> A1) and "Unlink audio" in the
   Clip panel frees it onto its own lane so you can slide or move it. Music
   dropped from the bin goes to A3+ and lanes mix.

3. Multi-track / B-roll editing is real
   The Media card imports video, audio and images (referenced in place, not
   copied). Drag a tile onto a track. Scale / X / Y / Opacity / Crop / Fit in
   the Clip panel make picture-in-picture B-roll. Export re-encodes and builds
   the same composite.
